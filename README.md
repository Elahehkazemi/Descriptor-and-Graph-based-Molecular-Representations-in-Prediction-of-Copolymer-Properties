# Predicting Thermodynamic Properties of Copolymers Using Random Forest and Graph Neural Networks

This repository contains code and data for predicting thermodynamic properties of copolymers using two modeling approaches:

- **Random Forest (RF)** models based on molecular descriptors.
- **Graph Neural Networks (GNN)** using Chemprop's **wD-MPNN** architecture, which learns directly from SMILES-based molecular graphs.

The predicted properties include:
- Density (**ρ**)
- Specific heat capacities at constant pressure (**C<sub>p</sub>**) and volume (**C<sub>v</sub>**)
- Volume expansion coefficient (**γ**)
- Linear expansion coefficient (**α**)
- Bulk modulus (**K**)

---

## Overview

### 1. Random Forest (RF) Models

- **Single-task RF**:
  - Trains separate RF models for each property.
  - Uses descriptors generated by PaDEL-Descriptor software.
  - Evaluates model performance and identifies important features.

- **Multi-task RF**:
  - Trains a single RF model to predict all properties simultaneously.
  - Highlights shared feature importance across tasks.

### 2. Graph Neural Networks (GNN) with Chemprop

- **Single-task wD-MPNN**:
  - Predicts one property at a time using SMILES strings as input.
  - Internally constructs molecular graphs and trains a GNN.

- **Multi-task wD-MPNN**:
  - Predicts multiple properties simultaneously using a shared GNN.
  - Supports hyperparameter optimization and GPU acceleration.

---

## Features

- **Descriptor-Based Modeling**:
  - Uses PaDEL descriptors for RF models.
  - Performs feature selection and importance analysis.

- **Graph-Based Modeling**:
  - Uses Chemprop's wD-MPNN to learn from molecular graphs.
  - Automatically converts SMILES to graphs using Graph generator file.

- **Hyperparameter Optimization**:
  - Uses Bayesian optimization to tune Chemprop models.

- **Model Evaluation**:
  - Reports RMSE and R² metrics.
  - Provides visualizations of predictions and feature importance.

## Getting Started

### Prerequisites

Install the required libraries:

For Random Forest:

```bash
pip install pandas numpy scikit-learn matplotlib seaborn


```


For Chemprop:

```bash
pip install chemprop

```



### Downloading the Data

The dataset used for training and evaluation can be downloaded from [Zenodo](https://zenodo.org/records/13752405).  
Please ensure you place the downloaded files in the appropriate directory before running the scripts.
